# Tarot Mini App — Frontend

## Стек
React + TypeScript + Vite, Telegram Mini Apps (через `telegram-web-app.js`, подключён в `index.html`).

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Для полноценной проверки Telegram-специфичных
вещей (initData, safe area, тема) нужно открывать через Telegram (BotFather → Mini App URL,
или `ngrok`/аналог для локальной разработки).

## Структура

```
src/
├── components/   # переиспользуемые UI-компоненты
├── pages/        # экраны (пока только MainScreen)
├── hooks/        # useTelegramUser и т.д.
├── types/        # общие типы (SpreadType и т.д.)
└── services/      # (появится с интеграцией backend API)
```

## Реализовано
- Главный экран: приветствие, «Расклад дня», список раскладов (Карта дня / Любовь / Будущее),
  переход к истории и профилю (пока заглушки — `console.log`, экраны ещё не созданы).

## Продакшен-билд
```bash
npm run build
```
Результат — статика в `dist/`, готова к любому статическому хостингу
(Vercel, Netlify и т.п.). Не забудь задать `VITE_API_BASE_URL` на хостинге —
без неё фронтенд будет стучаться в `localhost:8000`.
