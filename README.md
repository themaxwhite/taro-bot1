# Tarot Mini App

Telegram Mini App с раскладами таро. React/TypeScript/Vite фронтенд +
FastAPI/Python backend + одностраничный лендинг.

## Структура
```
frontend/   — React/TS/Vite, все экраны (главный, расклад, результат, история, профиль)
backend/    — FastAPI, Tarot Engine (выбор карт и ориентация — только здесь)
landing/    — сайт-визитка на tarot-aurum.pages.dev (Vite + React, пререндер и SEO)
DEPLOYMENT.md — пошаговая инструкция деплоя в реальный Telegram
```

## Архитектурный принцип
Весь выбор карт, случайность и ориентация карты решаются **только** backend'ом
(`backend/app/tarot/engine.py`). Frontend ничего не решает сам — только
отображает то, что вернул API.

## Быстрый старт (локально)

Backend:
```bash
cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --port 8000
```

Frontend (в отдельном терминале):
```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Открыть `http://localhost:5173`. Полноценная проверка Telegram-специфики
(initData, safe area, тема) требует открытия через сам Telegram — см.
`DEPLOYMENT.md`.

Локально база — SQLite в один файл, никакой настройки не требует. В проде
`DATABASE_URL` указывает на управляемый Postgres.

## Что реализовано

**Расклады.** Тринадцать штук, разложенных на главной по четырём
разделам: «Что впереди» («Да или нет», «Будущее», «Неделя», «Месяц
впереди»), «Отношения» («Любовь», «Совместимость»), «Дело и выбор»
(«Работа и деньги», «Два пути») и «Глубокий разбор» («Зеркало», «Путь»,
«Подкова», «Кельтский крест»). Плюс «Карта дня» отдельным баннером. Полная колода из 78 карт,
анимация перетасовки и раздачи. «Карта дня» фиксируется на календарные сутки
(UTC), а не перевыпадается при каждом открытии экрана.

**Экраны.** Главный (с дневным AI-пожеланием), расклад/колода с полем вопроса,
результат, история, профиль с «темами», полом и знаком зодиака. Светлая и
тёмная темы с переключателем — по умолчанию светлая для всех. Навигация
использует нативную кнопку «назад» самого Telegram, а последний шаг
онбординга — нативную главную кнопку внизу шторки; вне Telegram (или на
клиенте старее Bot API 6.1) экраны рисуют свои кнопки как раньше.

**Оформление.** Иллюстрированная колода «Tarot Aurum» (78 карт + рубашка) —
статика в `frontend/public/cards/`, тёмно-бирюзовый и античное золото. Фоновый
звуки интерфейса — шорох переворачивающейся карты, отклик на касание,
аккорд открытого расклада — синтезируются прямо в браузере через Web Audio
API, без единого аудиофайла, и выключаются одним переключателем в профиле.
На касания добавлена родная тактильная отдача Telegram.

**AI.** Толкование расклада с учётом вопроса и «тем» из профиля, дневное
мотивирующее пожелание, платные уточняющие вопросы после толкования.
Провайдеры пробуются по очереди — Groq, затем Anthropic; если не
настроен ни один ключ, обе фичи спокойно откатываются на статичный текст.

**Деньги.** Подписка через ЮKassa — три тарифа в продаже: «Плюс», «Премиум»
(свой вопрос к раскладу своими словами) и «Магистр» (то же плюс личный чат с
поддержкой). «Базовый» снят с продажи и доживает у тех, кто уже на нём.
Витрину тарифов отдаёт backend, чтобы цена на экране не разошлась с ценой в
счёте.
Квоты на толкование, дополнительную карту и уточняющий вопрос, бесплатная дневная «энергия», реферальная
программа и промокод для владельца, чтобы тестировать платное без мерчанта.

**Чат с тарологом.** Свободный разговор, не привязанный к раскладу: ответ
учитывает последний расклад, знак зодиака и карту-покровителя, а история
переписки хранится и уходит в контекст следующего вопроса. Один вопрос стоит
5 энергии. Работает только через Groq и без ухода на платный Anthropic: при
исчерпанном лимите ждёт и повторяет попытку.

**Данные.** Postgres в проде (SQLite локально), схема под Alembic-миграциями —
расклады, подписки и платежи persistent, история и статистика профиля читают
реальные строки. Плюс
админ-дашборд с использованием и выручкой и ежедневные напоминания про карту
дня.
