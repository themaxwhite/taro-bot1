# Tarot Mini App

Telegram Mini App с раскладами таро. React/TypeScript/Vite фронтенд +
FastAPI/Python backend + одностраничный лендинг.

## Структура
```
frontend/   — React/TS/Vite, все экраны (главный, расклад, результат, история, профиль)
backend/    — FastAPI, Tarot Engine (выбор карт и ориентация — только здесь)
landing/    — сайт-визитка на tarot-aurum.pages.dev (Vite + React, пререндер и SEO)
DEPLOYMENT.md — пошаговая инструкция деплоя в реальный Telegram
```

## Архитектурный принцип
Весь выбор карт, случайность и ориентация карты решаются **только** backend'ом
(`backend/app/tarot/engine.py`). Frontend ничего не решает сам — только
отображает то, что вернул API.

## Быстрый старт (локально)

Backend:
```bash
cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --port 8000
```

Frontend (в отдельном терминале):
```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Открыть `http://localhost:5173`. Полноценная проверка Telegram-специфики
(initData, safe area, тема) требует открытия через сам Telegram — см.
`DEPLOYMENT.md`.

Локально база — SQLite в один файл, никакой настройки не требует. В проде
`DATABASE_URL` указывает на управляемый Postgres.

## Что реализовано

**Расклады.** Семь штук: «Карта дня», «Любовь», «Будущее», «Кельтский крест»,
«Да или нет», «Подкова» и «Совместимость» (на двоих). Полная колода из 78 карт,
анимация перетасовки и раздачи. «Карта дня» фиксируется на календарные сутки
(UTC), а не перевыпадается при каждом открытии экрана.

**Экраны.** Главный (с дневным AI-пожеланием), расклад/колода с полем вопроса,
результат, история, профиль с «темами», полом и знаком зодиака. Светлая и
тёмная темы с переключателем — по умолчанию светлая для всех.

**Оформление.** Иллюстрированная колода «Tarot Aurum» (78 карт + рубашка) —
статика в `frontend/public/cards/`, тёмно-бирюзовый и античное золото. Фоновый
эмбиент синтезируется прямо в браузере через Web Audio API, без аудиофайлов.

**AI.** Толкование расклада с учётом вопроса и «тем» из профиля, дневное
мотивирующее пожелание, платные уточняющие вопросы после толкования.
Провайдеры пробуются по очереди — Gemini, затем Groq, затем Anthropic; если не
настроен ни один ключ, обе фичи спокойно откатываются на статичный текст.

**Деньги.** Подписка через ЮKassa (тарифы «Базовый» и «Плюс»), квоты на
толкование и дополнительную карту, бесплатная дневная «энергия», реферальная
программа и промокод для владельца, чтобы тестировать платное без мерчанта.

**Данные.** Postgres в проде (SQLite локально) — расклады, подписки и платежи
persistent, история и статистика профиля читают реальные строки. Плюс
админ-дашборд с использованием и выручкой и ежедневные напоминания про карту
дня.
